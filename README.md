# Betekrstian Sunday School

An interactive web app that teaches the Ethiopian Orthodox Tewahedo Church English Sunday school lessons
(compiled by Kesis Solomon Mulugeta for Bole Debre Salem Medhanealem Church) to young children, with Ethiopian art throughout.

Plain static files, no build step. Open `index.html` through any web server (for example `python3 -m http.server`).

## How it is organised

| Path | What it is |
| --- | --- |
| `index.html` | Home: four levels, every lesson of the church year. Unbuilt lessons open as text for a parent or teacher. |
| `lesson.html?id=L1-oct4` | The lesson player. Loads `data/lessons/<id>.js`. |
| `lessons/creation.html` | The first hand-built prototype (Level I, Creation I to III). |
| `js/art.js` | Shared drawings: people, holy figures, animals, objects and backgrounds. |
| `js/player.js` | Lesson engine and the shared games: cover, story, drag, tapmany, find, order, quiz, song, cross, finish. |
| `js/voice.js` | Narration, pronunciation and sound effects. |
| `data/curriculum.js` | All 187 lessons from the PDFs (generated by `tools/build_curriculum.py`). |
| `data/lessons/*.js` | One file per interactive lesson. Lesson ids are `L<level>-<month><week>`. |
| `data/lexicon.js` | Every Amharic and Ge'ez word, with Fidel, Latin spelling, meaning and how it is voiced. |
| `data/songs.js` | The mezmur from the lessons. |
| `data/audio.js` | List of recorded audio files that exist. |
| `tools/words.html` | Pronunciation list to review every word. |
| `tools/autoplay.js` | Plays every page of a lesson in a headless browser and reports pages that can't be finished. |

## Narration and pronunciation

Spoken lines mark Amharic and Ge'ez words as `[[key]]` (see `data/lexicon.js`). Each line can be replaced by a recording:

- `audio/lines/<lessonId>.<lineId>.mp3` for a whole line (for example ElevenLabs English narration)
- `audio/words/<key>.mp3` for one word, reused everywhere it appears
- `audio/songs/<songId>.mp3` for a mezmur

Add the key to `data/audio.js` after adding a file. Without a recording, English uses the device voice, Amharic words use an
Amharic device voice if there is one or else an English-voice respelling, and Ge'ez words stay silent. Latin transliterations are never read by the English voice.

## Adding a lesson

1. Copy a file in `data/lessons/`, rename it to the lesson id, and write its pages.
2. Add the id with its home-screen icon to `BUILT` in `tools/build_curriculum.py` and rebuild `data/curriculum.js`.
3. Run `node tools/autoplay.js http://localhost:8000 <id>` to check every page can be finished.

Holy images and all Amharic and Ge'ez text are to be reviewed by clergy before publishing.
